# Ski Park

A 3D freeski and snowboard trick game that runs in the browser. Pick a park, carve, hit kickers, rails, cliff drops and halfpipes, and chain tricks.

Open `index.html`, or visit the GitHub Pages site for this repo.

Needs an internet connection (three.js loads from a CDN). Friends, sesh, leaderboards and cloud saves only work inside the claude.ai version.
